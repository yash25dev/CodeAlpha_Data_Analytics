# CodeAlpha Data Analytics Internship

This repository contains my Data Analytics Internship tasks completed using Python.

## Tasks Completed

### Task 1: Web Scraping
- Extracted book titles, prices, ratings, and availability using BeautifulSoup.
- Exported the collected information to CSV.

### Task 2: Exploratory Data Analysis (EDA)
- Explored the Iris dataset using Pandas and NumPy.
- Examined descriptive statistics, missing values, duplicates, and correlations.
- Generated data visualizations.

### Task 3: Data Visualization
- Created bar charts, histograms, scatter plots, box plots, and a correlation heatmap.
- Used Matplotlib and Seaborn to communicate data insights.

### Task 4: Sentiment Analysis
- Analyzed sample customer product reviews using VADER.
- Classified reviews as positive, negative, or neutral.
- Exported sentiment scores and generated charts.

## Technologies Used
- Python
- Pandas and NumPy
- BeautifulSoup and Requests
- Matplotlib and Seaborn
- Scikit-learn
- VADER Sentiment Analyzer

## How to Run
1. Install Python.
2. Install the required libraries using `pip install -r requirements.txt`.
3. Open the relevant task folder.
4. Run the corresponding Python script.
